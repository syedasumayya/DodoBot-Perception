Confusion matrix (Random Forest) — peace/two_up pair highlighted:
peace row:   29-33 correct, 21-26 misclassified as two_up
two_up row:  40-41 correct, 12-14 misclassified as peace

Diagnosis: both a tree-based model and a neural network hit the same wall on
the same class pair -> the confusion is inherent to the landmark features for
these two visually-similar gestures, not a weak-classifier problem.

Decision: drop two_up. `peace` maps to "menu/bill request" in the gesture
table (intuitive, likely used); `two_up` was an arbitrary custom mapping to
"navigation command" that `one` (pointing) can reasonably cover instead.
